# catatan-web

Latihan bikin front-end sederhana tanpa framework dulu, biar paham dasarnya.

## Fitur

- Fetch data dari API publik
- Render list dinamis
- CSS manual, minim class

## Cara pakai

```bash
git clone https://github.com/Stormexpert2578/catatan-web.git
cd catatan-web
npm install
npm start
```

Contoh menjalankan:

```bash
buka index.html langsung di browser
```

## Struktur

```
index.js
public/style.css
```
